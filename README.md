# Adrobot — обёртка над Keitaro

Тестовое задание. Веб-приложение, которое через Admin API Keitaro:

1. **создаёт кампанию** по названию, гео и офферу — с двумя потоками, доменом, группой и источником;
2. **редактирует офферы в потоке** существующей кампании: добавление, удаление, возврат, закрепление долей, публикация и отмена черновика.

Стек: FastAPI, SQLAlchemy 2, Alembic, SQLite (или любая база, которую понимает SQLAlchemy), Vue 3 без сборки.

## Запуск

Нужен Python 3.11 или новее.

```bash
git clone https://github.com/gev566/keitaro-wrapper.git
cd keitaro-wrapper

python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

pip install -r requirements.txt
```

### Настройки

Скопируйте `.env.example` в `.env` и заполните два значения:

```
KEITARO_URL=https://адрес-трекера
KEITARO_API_KEY=ключ из админки Keitaro (Профиль → API ключи)
```

Остальные настройки описаны в `.env.example` и имеют значения по умолчанию.

### Миграции

```bash
alembic upgrade head
```

Команда создаёт таблицы в базе из `DATABASE_URL` (по умолчанию файл `adrobot.db`).
Новая миграция после изменения моделей: `alembic revision --autogenerate -m "описание"`.

### Старт

```bash
uvicorn app.main:app --reload
```

Интерфейс: http://127.0.0.1:8000 · документация API (Swagger): http://127.0.0.1:8000/docs

### Тесты

```bash
python -m pytest
```

18 тестов: расчёт долей и все сценарии редактора. Настоящий Keitaro для тестов не нужен — он подменяется объектом в памяти.

### Проверка без Keitaro

В `tools/mock_keitaro.py` лежит заглушка, которая повторяет нужные методы Admin API:

```bash
uvicorn tools.mock_keitaro:app --port 9000
```

и в `.env`: `KEITARO_URL=http://127.0.0.1:9000`, `KEITARO_API_KEY=mock`.

## Как это работает

### Создание кампании

Форма принимает название, гео (один или несколько двухбуквенных кодов через запятую) и оффер (поиск с автокомплитом по названию или ID).

Приложение создаёт в Keitaro:

- кампанию с доменом, группой и источником (по умолчанию ищутся по именам из `.env`, их можно поменять в форме);
- **поток 1** — фильтр «страна из списка», редирект на `GEO_REDIRECT_URL`;
- **поток 2** — выбранный оффер с долей 100 %.

Ротация потоков — по позиции, поэтому сначала проверяется поток 1, остальные посетители попадают в поток 2.
Если кампания создалась, а потоки — нет, кампания удаляется, чтобы в трекере не оставалось мусора.
Префикс `CAMPAIGN_PREFIX` добавляется к названию автоматически.

### Редактор потока

Логика повторяет демо из ТЗ.

| Действие | Что происходит |
|---|---|
| **Fetch streams from KT** | Забираем потоки из Keitaro. Потоки без офферов показываются одной строкой. Оффер, который пропал из Keitaro, не удаляется, а получает статус `removed`. |
| **Add** | Оффер добавляется в черновик, доли пересчитываются, поток становится «жёлтым». В Keitaro пока ничего не меняется. |
| **Remove** | Доля оффера становится 0, он сереет и остаётся в архиве потока. |
| **Bring back** | Удалённый оффер возвращается в поток. |
| **📌 (pin)** | Доля закрепляется (её можно ввести вручную) и не меняется при пересчётах. |
| **Push to KT** | Черновик отправляется в Keitaro. Проверяется, что сумма долей равна 100 % и в потоке есть хотя бы один оффер. |
| **Cancel** | Черновик сбрасывается к последнему опубликованному состоянию; неопубликованные офферы отвязываются. |

**Расчёт долей** (`app/weights.py`): сумма всегда 100; закреплённые доли не трогаем; остаток делится поровну; если поровну не делится, лишние проценты получают первые офферы (100 на троих — 34, 33, 33).

**Черновик** хранится в таблице `stream_offers`: поля `status`, `share`, `pinned` — текущее состояние в интерфейсе, поля `pub_*` — состояние на момент последней синхронизации. Поток «жёлтый», когда они различаются.

## Структура

```
app/
  config.py     настройки из .env
  db.py         подключение к базе
  models.py     таблицы: campaigns, streams, stream_offers
  keitaro.py    клиент Admin API Keitaro
  weights.py    расчёт долей
  services.py   бизнес-логика
  main.py       HTTP API и раздача интерфейса
  static/       интерфейс: index.html, app.js, style.css, Vue
migrations/     миграции Alembic
tests/          тесты
tools/          заглушка Keitaro
```

## Допущения и ограничения

- Кнопка Fetch сбрасывает неопубликованный черновик: источником правды считается Keitaro.
- Статистика и тренды по офферам (колонки Stats и Trends из демо) не реализованы.
- Авторизации нет: приложение рассчитано на запуск внутри закрытой сети.
- Список офферов запрашивается из Keitaro при каждом поиске, без кеша.
